# Hospital Management System – SQL Data Analysis

## Project Overview
This project focuses on analyzing a Hospital Management System database using MySQL. It demonstrates SQL skills through database creation, data insertion, table relationships, and solving 50 practical SQL analysis questions.

## Tools & Technologies
- MySQL
- MySQL Workbench
- SQL

## Database Structure

The project contains four tables:

1. **Departments** – Department details and floor information.
2. **Doctors** – Doctor information and department assignments.
3. **Patients** – Patient details and registration information.
4. **Appointments** – Appointment records connecting patients and doctors.

## Project Files

| File | Description |
|---|---|
| `01_create_tables.sql` | Database and table creation |
| `02_insert_data.sql` | Inserting sample records |
| `03_Analysis_queries.sql` | 50 SQL analysis questions and solutions |

## SQL Concepts Practiced

- SELECT, WHERE, ORDER BY and DISTINCT
- Aggregate functions (COUNT, SUM, AVG, MIN, MAX)
- GROUP BY and HAVING
- INNER JOIN and other table joins
- Subqueries
- CASE WHEN
- Date functions
- Data filtering and analysis

## Project Objectives

- Design a relational hospital database.
- Establish relationships between tables.
- Retrieve and analyze hospital data.
- Practice SQL queries using real-world business scenarios.
- Strengthen SQL skills for Data Analyst roles.

## Key Learning Outcomes

- Improved understanding of relational databases.
- Practical experience writing SQL queries.
- Experience analyzing data across multiple related tables.
- Better understanding of data aggregation and reporting.
